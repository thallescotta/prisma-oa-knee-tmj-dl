# PDFs dos estudos incluídos

Nome do arquivo = chave BibTeX. A lista completa, com links e licenças, está em `../docs/lista_pdfs.md`.

Só entram aqui PDFs cuja licença permite redistribuição: CC BY, ou CC BY-NC-ND desde que o arquivo não seja alterado.
Antes de subir, confira a licença impressa na primeira página do artigo.
Os estudos marcados com "NÃO" em `docs/lista_pdfs.md` ficam só no seu computador; para eles, o link do DOI basta.

Para baixar os que estão no PubMed Central: `python src/download_oa_pdfs.py`.
